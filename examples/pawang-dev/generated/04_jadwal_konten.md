# Jadwal Konten Pawang.dev: Hari, Jam, dan Topik

Menjawab: **posting apa, hari apa, jam berapa, topik apa**. Siap dipakai mulai **Senin, 26 Okt 2026** (4 minggu), lalu diulang atau diperbarui dengan command di Bagian 7.

Asumsi: audiens pemilik UMKM dan tim operasional di Indonesia (WIB), waktu **WIB**, tim kecil (1-2 orang).

---

## 1. Dua Paket Ritme (pilih satu)

| Paket | Frekuensi | Cocok untuk |
|---|---|---|
| **Ringan** | 3 konten utama per minggu (tanda ★ di kalender) + story | Mulai dari nol, tim 1 orang |
| **Standar** | 5-7 konten utama per minggu + story harian | Sudah rutin, ingin tumbuh lebih cepat |

Aturan terpenting: **konsisten lebih penting daripada banyak.** Lebih baik 3 konten rutin selama 3 bulan daripada 7 konten lalu berhenti dalam 2 minggu.

### 3.3 Tentang jam posting

Panduan jam posting di internet **tidak konsisten dan kebanyakan berupa artikel blog**, bukan data resmi platform. Pola yang berulang: untuk konten bisnis/B2B, jam kerja pagi (sekitar 09:00-11:00) dan jam istirahat (12:00-15:00) di hari kerja; untuk TikTok/Reels, siang (11:00-13:00) dan malam (19:00-22:00). Karena itu jam di tabel ini adalah **hipotesis awal**, bukan kepastian. Cara memastikannya ada di Bagian 9 (evaluasi 4 minggu dengan Insights akun Anda sendiri).

Tips teknis: unggah beberapa menit sebelum jam target agar sempat diproses, dan gunakan penjadwalan bawaan (Meta Business Suite atau scheduler Instagram/TikTok) supaya jam tetap tepat.

## 7. Command Pembuat Jadwal (jalankan di ChatGPT atau Claude)

Tempel Brand Lock dan Voice Lock dulu (dari file sebelumnya).

### /pw-j-kalender
```
/pw-j-kalender Buat kalender konten {4 / 8 / 12} minggu mulai {tanggal Senin} untuk Pawang.dev. Paket {Ringan / Standar}. Platform: {Instagram, WhatsApp, TikTok/Reels, LinkedIn, X, Pinterest, blog}. Gunakan pilar (Paham 35%, Jinak 25%, Tenang 20%, Si Liar 15%, Ajakan 5%). Setiap minggu punya satu tema. Output tabel per minggu: Tanggal | Jam (WIB) | Platform | Format | Pilar | Topik/judul | Command yang dipakai (/pw-, /pw-v-, /pw-t-) | Tanda minimal. Pertimbangkan momen {11.11, 12.12, Ramadan, akhir tahun} bila relevan dan tandai topik yang butuh data nyata dari saya. Jangan mengarang angka atau testimoni.
```

### /pw-j-mingguan
```
/pw-j-mingguan Dari kalender saya untuk minggu {tanggal}, buatkan paket kerja minggu itu: (1) daftar konten per hari dengan jam posting, (2) prompt pembuat teks yang siap ditempel untuk tiap konten, (3) daftar gambar dan video yang harus dibuat, (4) caption dan hashtag, (5) daftar periksa sebelum jadwalkan. Kalender: {tempel baris minggu itu}.
```

### /pw-j-topik
```
/pw-j-topik Beri 20 ide topik baru untuk pilar {nama pilar} yang belum ada di daftar berikut: {tempel topik yang sudah dipakai}. Untuk tiap ide: judul (maksimal 8 kata), format terbaik (carousel/reel/story/kartu), dan alasan satu kalimat. Hindari klaim yang tidak bisa dibuktikan.
```

### /pw-j-daur
```
/pw-j-daur Untuk topik "{topik}", buat rencana daur ulang: carousel IG, reel, 3 story, kartu tips, thread X, post LinkedIn, pin Pinterest, status WhatsApp, dan outline artikel blog. Berikan hari dan jam posting tiap versi dalam 10 hari agar tidak menumpuk, serta command yang dipakai.
```

### /pw-j-batch
```
/pw-j-batch Susun jadwal produksi batch untuk {jumlah} konten minggu depan dengan tim {1 / 2} orang dan waktu {jam per minggu}. Output: jadwal per hari (topik, teks, gambar, video, editing, penjadwalan) dan prioritas jika waktu kurang.
```

### /pw-j-evaluasi
```
/pw-j-evaluasi Ini data Insights {4 minggu terakhir}: {tempel tabel: tanggal, jam, format, jangkauan, simpan, bagikan, komentar, klik link, pesan masuk}. Analisis: (1) jam dan hari terbaik untuk tiap format, (2) pilar dan format yang paling menghasilkan simpan/bagikan/pesan, (3) yang sebaiknya dikurangi, (4) revisi jadwal minggu berikutnya. Beri alasan berbasis data saya dan tandai bila sampel terlalu kecil untuk disimpulkan.
```

### /pw-j-momen
```
/pw-j-momen Daftar momen dan hari penting dalam {bulan tahun} yang relevan untuk audiens saya di Indonesia, beserta ide konten untuk tiap momen. Tandai tanggal yang perlu saya verifikasi sendiri.
```

## 9. Evaluasi (setiap minggu 15 menit, setiap 4 minggu 1 jam)

### 9.1 Yang dicatat (satu baris per konten)

```
Tanggal | Jam | Platform | Format | Pilar | Topik | Jangkauan | Simpan | Bagikan | Komentar | Klik link | Pesan masuk | Catatan
```

### 9.2 Ukuran yang diprioritaskan

| Ukuran | Alasan |
|---|---|
| Pesan masuk / konsultasi | paling dekat dengan bisnis |
| Simpan dan bagikan | tanda konten bermanfaat |
| Klik link ke website | minat lanjut |
| Jangkauan | hanya pelengkap, mudah naik tapi tidak selalu bernilai |

### 9.3 Cara menguji jam posting
1. Jalankan jadwal di Bagian 3 selama 4 minggu tanpa mengubah jam.
2. Lihat Insights Instagram/TikTok: jam dan hari ketika **pengikut Anda sendiri** paling aktif.
3. Geser satu atau dua slot ke jam itu, lalu bandingkan 4 minggu berikutnya.
4. Ubah satu hal pada satu waktu agar hasilnya bisa dibaca.

### 9.4 Aturan keputusan sederhana
- Format yang selalu di bawah rata-rata selama 4 kali berturut-turut: ubah atau kurangi.
- Pilar yang paling banyak menghasilkan pesan masuk: tambah porsinya 5-10%.
- Jika tim kelelahan: turun ke paket Ringan, jangan berhenti total.
