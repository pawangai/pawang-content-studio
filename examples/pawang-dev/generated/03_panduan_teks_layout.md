# Panduan Teks, Layout, dan Waktu Pawang.dev (Canva & CapCut)

Menjawab tiga pertanyaan: **teks apa yang diisi**, **ditaruh di mana**, dan **muncul di detik berapa**.
Gambar/video dibuat di ChatGPT dan Flow **tanpa teks**; semua tulisan ditambahkan di Canva atau CapCut memakai panduan ini.

Cara pakai cepat:
1. Pilih format di Bagian 2-6 (carousel, story, foto, reel/short, thumbnail).
2. Salin teks contoh, atau jalankan command `/pw-t-...` di Bagian 8 untuk membuat teks sesuai topik Anda.
3. Ikuti tabel posisi dan waktu, lalu atur di Canva/CapCut (Bagian 9).

## 1. Aturan Dasar (berlaku untuk semua format)

### 1.1 Gaya teks brand

| Elemen | Aturan |
|---|---|
| Font judul | Plus Jakarta Sans, ExtraBold/Bold |
| Font isi | Inter, Regular/Medium |
| Warna teks di latar gelap | Putih Tulang #FAFAF7 |
| Warna teks di latar terang | Biru Malam #14213D |
| Kata penekanan | Api Dupa #FF8A3D (maksimal 1-2 kata per layar) |
| Tombol/CTA | Latar Api Dupa #FF8A3D, teks Biru Malam #14213D |
| Latar kartu/pendukung | Krem #FFF6E9, Hijau Sage #A7C4A0 |
| Logo | Kecil di pojok, jangan menutupi Si Liar |

Kontras: teks Putih Tulang di atas Biru Malam, atau Biru Malam di atas Krem. Hindari Api Dupa sebagai warna teks panjang di atas Krem.

### 1.2 Batas jumlah kata

| Jenis teks | Maksimal |
|---|---|
| Hook / judul utama | 6-8 kata |
| Subteks | 12-15 kata |
| Isi slide carousel | 25-30 kata |
| Teks di video per layar | 6 kata per baris, maksimal 2 baris |
| Tombol CTA | 2-4 kata |

### 1.3 Ukuran font (patokan, kanvas lebar 1080 px)

| Elemen | Ukuran |
|---|---|
| Judul utama | 72-110 px |
| Subjudul | 44-56 px |
| Isi | 36-44 px |
| Teks kecil (nomor, handle) | 26-32 px |
| Teks video di ponsel | tidak kurang dari 48 px |

Tes cepat: perkecil layar ke ukuran ponsel; jika masih terbaca, ukuran sudah aman.

### 1.4 Zona aman (agar tidak tertutup tampilan aplikasi)

Angka berikut patokan umum; tampilan aplikasi bisa berubah, jadi lihat panduan resmi platform bila ragu.

| Format | Atas | Bawah | Samping |
|---|---|---|---|
| IG Story / WA Status (1080x1920) | kosongkan ±250 px | kosongkan ±340 px | ±60 px |
| Reels / TikTok / Shorts (1080x1920) | kosongkan ±250 px | kosongkan ±450 px | kanan ±140 px (ikon suka/komentar) |
| Post / carousel IG (1080x1350) | ±90 px | ±90 px | ±90 px |
| OG image (1200x630) | ±60 px | ±60 px | ±80 px |

### 1.5 Waktu tampil teks di video

Rumus: **durasi tampil minimal = 1 detik + 0,3 detik x jumlah kata.**
Contoh: 6 kata = 1 + 1,8 = **±2,8 detik**. Jangan menaruh teks di bawah 1,5 detik.

## 2. Carousel Instagram (1080x1350, 7 slide)

### 2.1 Pola layout 7 slide

| Slide | Isi | Layout | Latar |
|---|---|---|---|
| 1 | Hook | Judul 90-110 px di sepertiga atas; subteks kecil di bawah judul; logo kecil pojok kiri atas; panah geser pojok kanan bawah | Biru Malam |
| 2 | Masalah | Kalimat besar 70-80 px di tengah; ikon kecil Hijau Sage | Krem |
| 3-6 | Satu poin per slide | Angka besar (Api Dupa, 160 px) di kiri atas; judul poin 64 px; penjelasan 40 px maksimal 2 kalimat; nomor "3/7" pojok kanan atas | Bergantian Krem dan Biru Malam |
| 7 | CTA | Kalimat ajakan 72 px; tombol Api Dupa di tengah bawah; handle/URL di bawah tombol; logo di atas | Biru Malam |

Footer semua slide: logo kecil (lebar ±120 px) kiri bawah, nomor slide kanan atas, margin 90 px.

## 3. Story (IG, WA Status) 1080x1920

### 3.1 Pola layout 3 zona

| Zona | Posisi | Isi |
|---|---|---|
| Atas (250 px kosong) | tidak ada teks | area UI aplikasi |
| Zona judul | sepertiga atas, di bawah 250 px | judul 80-100 px, maksimal 8 kata |
| Zona visual | tengah | Si Liar atau gambar utama |
| Zona aksi | di atas 340 px dari bawah | tombol/stiker/CTA |
| Bawah (340 px kosong) | tidak ada teks | area balas pesan |

### 3.2 Urutan 4 story (satu hari)

| Story | Tujuan | Teks contoh |
|---|---|---|
| 1 | Hook / pertanyaan | `Laporan bisnismu masih disalin manual?` |
| 2 | Masalah | `Rawan salah. Makan waktu. Bikin pusing.` |
| 3 | Solusi | `Pawang Sheet: angka berantakan jadi dashboard rapi.` |
| 4 | CTA | `Mau dicoba? Konsultasi Gratis -> pawang.dev` |

### 3.3 Stiker interaktif
Taruh stiker polling/pertanyaan di zona aksi, satu per story. Contoh format: `{pertanyaan singkat}? Ya / Tidak` atau `Tanya seputar {topik}`.

### 3.4 WhatsApp Status
Sama seperti story, tetapi teks lebih besar (judul 100-120 px) dan CTA berbentuk ajakan chat: `Balas "INFO" untuk konsultasi gratis`.

## 4. Post Foto / Gambar Tunggal (1080x1350)

| Zona | Isi |
|---|---|
| Sepertiga atas | Headline 80-100 px, maksimal 8 kata |
| Tengah | Visual (Si Liar, ilustrasi layanan, dashboard) |
| Bawah | Subteks 40 px, lalu logo kecil dan `pawang.dev` |

Contoh teks:
```
Headline: Website jinak: cepat, rapi, mudah diurus.
Subteks: Pawang Web untuk usaha yang ingin tampil tenang di dunia digital.
Footer: pawang.dev
```

```

Angka: "4 tanda data bisnismu sudah liar"
Pertanyaan: "Digitalmu liar?"
Janji: "Dari kusut jadi rapi, tanpa istilah ribet."
```

## 5. Reels / TikTok / Shorts (9:16)

### 5.1 Struktur waktu

| Durasi total | Hook | Masalah | Solusi | Bukti/hasil | CTA |
|---|---|---|---|---|---|
| 15 detik | 0:00-0:02 | 0:02-0:05 | 0:05-0:10 | 0:10-0:13 | 0:13-0:15 |
| 24 detik | 0:00-0:03 | 0:03-0:08 | 0:08-0:15 | 0:15-0:20 | 0:20-0:24 |
| 30-45 detik | 0:00-0:03 | 0:03-0:12 | 0:12-0:28 | 0:28-0:38 | 0:38-0:45 |

Aturan: hook muncul **sebelum detik ke-3**; CTA tampil **3-4 detik terakhir**; ganti visual atau teks setiap 2-4 detik.

### 5.2 Contoh lengkap 24 detik: "Si Liar Menjinakkan Data"

| Waktu | Visual | Teks di layar | Posisi | Animasi teks |
|---|---|---|---|---|
| 0:00-0:03 | Klip 1: tokoh terlilit kabel dan kertas | `Data bisnismu juga liar begini?` | Tengah atas (di bawah 250 px) | Pop membesar, 100 px |
| 0:03-0:06 | Klip 1 (lanjut) | `Satu angka, lima file.` | Bawah tengah, di atas 450 px | Fade in, 56 px |
| 0:06-0:09 | Klip 2: cahaya oranye menyala | `Lalu ketemu Pawang.` | Tengah atas | Geser dari kiri, 90 px |
| 0:09-0:12 | Klip 2 (lanjut) | `Kami pahami dulu masalahnya.` | Bawah tengah | Fade in, 52 px |
| 0:12-0:15 | Klip 3: layar kusut tertata | `Paham -> Tenang -> Jinak` | Tengah | Muncul satu per satu |
| 0:15-0:18 | Klip 3 (lanjut) | `Data kusut jadi dashboard rapi.` | Bawah tengah | Fade in |
| 0:18-0:21 | Klip 4: tokoh tenang melambai | `Rapi. Tenang. Jalan sendiri.` | Tengah atas | Pop |
| 0:21-0:24 | Klip 4 (penutup) | `Tombol Konsultasi Gratis + pawang.dev + logo` | Tengah bawah, di atas 450 px | Tombol muncul memantul |

Subtitle suara (jika ada narasi): bawah tengah, 48 px, Putih Tulang dengan bayangan lembut, maksimal 2 baris.

### 5.3 Bank hook (3 detik pertama)

```
Pertanyaan: "Laporan bisnismu masih disalin manual?"
Kejutan: "Ini yang terjadi kalau data dibiarkan liar."
Angka: "3 tanda websitemu bikin pelanggan pergi."
Kontras: "Sebelum vs sesudah dijinakkan."
Tantangan: "Coba hitung: berapa file untuk satu laporan?"
```

### 5.4 Bank CTA

```
"Konsultasi Gratis → pawang.dev"
"Chat kami, kita jinakkan bareng."
"Simpan video ini, kirim ke temanmu yang datanya liar."
"Komentar 'INFO' dan kami kirim detailnya."
```

### 5.5 Pengaturan audio dan caption
- Musik pelan; narasi atau efek bunyi lebih keras daripada musik.
- Aktifkan caption otomatis di CapCut untuk narasi, lalu perbaiki ejaan manual.
- Taruh caption di zona aman bawah (di atas 450 px dari tepi bawah).

## 7. Caption dan Hashtag (di luar gambar)

### 7.1 Struktur caption (Instagram)

```
Baris 1 (hook, ulangi ide gambar): ...
Baris 2-4 (nilai: 2-3 kalimat pendek): ...
Baris 5 (CTA): Konsultasi Gratis → pawang.dev
Baris 6: 3-5 hashtag relevan
```

Contoh:
```
Cari satu angka, buka lima file? Itu tanda data bisnismu mulai liar.
Kabar baiknya, bisa dijinakkan tanpa istilah teknis yang bikin pusing.
Geser untuk 4 tandanya, lalu cek mana yang kamu alami.
Mau dibantu? Konsultasi Gratis → pawang.dev
#digitalbisnis #otomasiusaha #dashboardbisnis #umkmdigital
```

### 7.2 Panjang caption
Reels/TikTok/Shorts: 1-3 baris. Carousel: 4-6 baris. Story: tanpa caption, cukup stiker.

## 8. Command untuk Membuat Teks (jalankan di ChatGPT atau Claude)

Tempel dulu **Voice Lock** ini sekali per chat:

```
VOICE LOCK - Pawang.dev
Suara brand: tenang, paham, jinak; hangat, ramah, tidak menakut-nakuti dengan istilah teknis.
Tagline: "Digitalmu liar? Serahkan ke Pawang."
CTA standar: "Konsultasi Gratis → pawang.dev"
Bahasa Indonesia santai-profesional, kalimat pendek.
Hindari: dijamin, pasti, 100%, terbaik, nomor 1, garansi.
Aturan: hook maksimal 8 kata, teks video maksimal 6 kata per baris, jangan mengarang data atau testimoni.
```

### /pw-t-carousel
```
/pw-t-carousel Buat isi teks carousel Instagram 7 slide tentang "{topik}" untuk audiens {pemilik UMKM / tim operasional / ...}. Output berupa tabel dengan kolom: Slide | Teks (persis seperti akan ditulis) | Posisi di layar | Ukuran font | Catatan visual. Slide 1 hook maksimal 8 kata, slide 2 masalah, slide 3-6 satu poin per slide (angka, judul 5-7 kata, penjelasan maksimal 2 kalimat), slide 7 CTA. Setelah tabel, tulis caption Instagram 4-6 baris dan 4 hashtag. Jangan mengarang data.
```

### /pw-t-story
```
/pw-t-story Buat urutan {3 / 4 / 5} story Instagram atau WhatsApp Status tentang "{topik}". Output tabel: Story | Tujuan | Teks judul | Teks pendukung | Stiker interaktif yang disarankan | Posisi teks. Ikuti zona aman 250 px atas dan 340 px bawah. Story terakhir berisi CTA "Konsultasi Gratis → pawang.dev".
```

### /pw-t-reels
```
/pw-t-reels Buat naskah teks di layar untuk video {15 / 24 / 30} detik tentang "{topik}", memakai {4} klip visual: {jelaskan isi tiap klip}. Output tabel: Waktu (detik) | Visual | Teks di layar (maksimal 6 kata per baris) | Posisi | Animasi teks | Audio/narasi. Hook muncul sebelum detik ke-3, CTA di 3-4 detik terakhir, durasi tampil teks mengikuti rumus 1 detik + 0,3 detik per kata. Sertakan 3 pilihan hook alternatif dan caption 1-3 baris.
```

### /pw-t-foto
```
/pw-t-foto Buat 5 pilihan headline (maksimal 8 kata) dan satu subteks (maksimal 15 kata) untuk post gambar tunggal Instagram tentang "{topik}". Beri tiap pilihan label rumus (masalah-solusi / angka / pertanyaan / janji / kontras) dan sarankan posisi teks pada layout 1080x1350.
```

### /pw-t-hook
```
/pw-t-hook Beri 10 hook 3 detik pertama untuk video tentang "{topik}". Maksimal 8 kata, bervariasi: pertanyaan, kejutan, angka, kontras, tantangan. Tandai 2 yang paling kuat dan jelaskan alasannya dalam satu kalimat.
```

### /pw-t-thumbnail
```
/pw-t-thumbnail Beri 6 pilihan teks thumbnail (maksimal 4 kata, huruf kapital) dan teks OG image (maksimal 8 kata) untuk konten "{judul}". Sebutkan kata mana yang diberi warna Api Dupa pada tiap pilihan.
```

### /pw-t-caption
```
/pw-t-caption Buat caption {Instagram / TikTok / LinkedIn / X} untuk konten "{ringkasan konten}" dengan struktur: hook, 2-3 kalimat nilai, CTA, hashtag. Sesuaikan panjang dan nada dengan platform. Jangan mengarang klaim.
```

### /pw-t-cta
```
/pw-t-cta Beri 8 variasi CTA pendek (maksimal 4 kata untuk tombol, maksimal 12 kata untuk kalimat) untuk tujuan "{konsultasi / simpan / bagikan / komentar / klik link}" dengan nada Pawang.dev yang hangat, tanpa tekanan.
```

### /pw-t-lengkap
```
/pw-t-lengkap Untuk topik "{topik}", buat paket teks lengkap: (1) 3 pilihan hook, (2) isi carousel 7 slide, (3) urutan 4 story, (4) naskah teks video 24 detik, (5) caption IG dan hashtag, (6) teks thumbnail/OG. Pakai format tabel dengan kolom posisi, ukuran font, dan waktu. Konsisten dengan Voice Lock.
```

## 9. Langkah Teknis di Canva dan CapCut

### 9.1 Canva
1. Buat **Brand Kit**: tambahkan warna brand (Biru Malam #14213D, Api Dupa #FF8A3D, Krem #FFF6E9, Hijau Sage #A7C4A0, Putih Tulang #FAFAF7) dan font Plus Jakarta Sans + Inter.
2. Buat desain kustom sesuai ukuran di Bagian 1.4 (1080x1350 untuk carousel, 1080x1920 untuk story).
3. Tarik **panduan** (penggaris) untuk margin 90 px, atau 250/340 px untuk story.
4. Unggah gambar dari ChatGPT, taruh teks di layer atas sesuai tabel.
5. Simpan template (duplikat) agar topik berikutnya cukup mengganti teks.
6. Unduh PNG (carousel/story) atau MP4 (video).

### 9.2 CapCut
1. Proyek baru, rasio **9:16**, impor klip Flow berurutan di lini masa.
2. Tambah teks: pilih font mendekati Plus Jakarta Sans (atau impor font), ukuran tidak kurang dari 48 px, warna sesuai palet.
3. Atur durasi tiap teks di lini masa mengikuti tabel waktu (Bagian 5.2).
4. Beri animasi masuk sederhana (pop, fade, geser) 0,3-0,5 detik; hindari animasi berlebihan.
5. Tambahkan logo sebagai stiker/overlay di akhir video.
6. Caption otomatis untuk narasi, lalu koreksi manual.
7. Ekspor 1080p, 30 fps.

### 9.3 Daftar periksa sebelum unggah
- [ ] Hook muncul sebelum detik ke-3
- [ ] Teks tidak masuk zona UI (atas 250 px, bawah 450 px untuk video)
- [ ] Setiap teks tampil sesuai rumus durasi
- [ ] Warna hanya dari palet brand
- [ ] Ejaan dan angka sudah diperiksa
- [ ] CTA dan URL jelas di akhir
- [ ] Logo tidak menutupi Si Liar
