## Temuan

- Format untuk pesan masuk per posting: belum ada pemenang jelas (selisih kecil (Kartu tips vs Story: 1.17x < 1.25x)).
- Format untuk tingkat simpan: belum ada pemenang jelas (selisih kecil (Reel vs Testimoni: 1.01x < 1.25x)).
- **Pilar terbaik untuk pesan masuk per posting:** Jinak (1.47x grup kedua (Paham), n=4).
- Pilar untuk tingkat simpan: belum ada pemenang jelas (selisih kecil (Si Liar vs Paham: 1.00x < 1.25x)).
- **Platform terbaik untuk jangkauan:** Reels (2.36x grup kedua (Instagram), n=8).
- **Bucket terbaik untuk jangkauan:** siang 11-14 (1.32x grup kedua (pagi 06-10), n=8).
- Tren jangkauan (median paruh pertama vs kedua): 832 -> 862 (+4%).
- Posting paling menghasilkan pesan/simpan: 2026-11-11 Story 'topik 2-2' (pesan 2, simpan 2.97%); 2026-11-16 Carousel 'topik 3-0' (pesan 2, simpan 2.97%); 2026-11-03 Reel 'topik 1-1' (pesan 2, simpan 2.95%).

## Saran Revisi Kalender

1. Pindahkan konten utama ke waktu **siang 11-14** (jangkauan median tertinggi, n=8); uji 4 minggu sebelum mengunci.
2. Tambah porsi pilar **Jinak** 5-10 poin (pesan masuk per posting tertinggi), kurangi dari pilar dengan hasil terendah dan n cukup.
3. Format **Reel** paling lemah untuk pesan dan simpan (pesan 0.25/posting, simpan 2.96%). Namun Reel memiliki jangkauan median tertinggi (1736); mungkin berperan sebagai pintu masuk, bukan pendorong pesan, jadi perbaiki CTA-nya sebelum mengurangi.
