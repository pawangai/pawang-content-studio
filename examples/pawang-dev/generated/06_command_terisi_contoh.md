# Command Siap Tempel

Tempel Brand Lock dan upload brand board dulu (sekali per chat), lalu salin command di bawah satu per satu.

### /pw-logo (Singkat)
```
/pw-logo Versi horizontal di latar bersih.
```

### /pw-logo (Detail)
```
/pw-logo Buat ulang logo Pawang.dev sesuai brand board: huruf P dengan lingkaran oranye dan percikan bintang, wordmark "Pawang" dengan ".dev" lebih kecil di bawah kanan. Versi contoh. Latar Krem #FFF6E9. Vektor bersih, tepi tajam, proporsi sama persis dengan board, tanpa efek bayangan, ruang bersih di sekeliling logo. Tampilkan juga versi kecil 64px untuk uji keterbacaan.
```

### /pw-profil (Singkat)
```
/pw-profil Foto profil bulat untuk Instagram.
```

### /pw-profil (Detail)
```
/pw-profil Foto profil contoh: logo Pawang.dev di tengah area aman lingkaran, latar Biru Malam #14213D, tanpa teks tambahan, kontras tinggi, tetap jelas pada ukuran 110px. Rasio 1:1.
```

### /pw-mascot (Singkat)
```
/pw-mascot Si Liar pose.
```

### /pw-mascot (Detail)
```
/pw-mascot Si Liar maskot Pawang.dev sedang memegang laptop. Pertahankan desain karakter persis seperti board: makhluk berbulu biru malam, syal oranye, tongkat kayu, daun hijau sage; ekspresif, imut, tidak menyeramkan. Ekspresi senang. Latar bersih. Gaya flat modern hangat, ilustrasi bersih, sudut membulat, banyak ruang kosong, sedikit tekstur lembut.
```
