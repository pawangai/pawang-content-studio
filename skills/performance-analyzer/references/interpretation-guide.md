# Panduan Menafsirkan Hasil

## Metrik dan fungsinya
| Metrik | Menjawab | Catatan |
|---|---|---|
| Jangkauan (median) | Seberapa jauh konten menyebar | pintu masuk; mudah naik, tidak selalu bernilai |
| Simpan % | Apakah isinya berguna | kuat untuk konten edukasi |
| Bagikan % | Apakah layak diteruskan | tanda nilai sosial |
| Komentar % | Apakah memicu diskusi | berguna untuk pertanyaan/polling |
| Klik % | Apakah memicu tindakan ke website | tergantung CTA dan posisi link |
| Pesan/posting | Apakah memicu percakapan bisnis | metrik terdekat dengan hasil |

Jika kolom satuan berbeda (tayangan di TikTok, jangkauan di Instagram), jangan membandingkan angka mutlak lintas platform; bandingkan di dalam platform.

## Ambang keputusan (bawaan skrip)
- Sampel minimum per grup: 4 posting.
- Pemenang: nilai terbaik >= 1,25x grup kedua dan keduanya n >= 4.
- Tren: bandingkan median paruh pertama vs kedua; perubahan di bawah 10% anggap datar.
- Outlier: jangkauan > 3x median.

## Faktor yang tercampur (confounding)
- Jam, hari, format, dan pilar sering bergerak bersama (mis. selalu carousel jam 09:00). Perbedaan hasil tidak bisa dipastikan karena jam.
- Solusi: uji A/B sederhana: format sama, dua jam berbeda, minimal 3-4 posting per jam, topik setara.

## Desain uji 4 minggu
```
Minggu 1-2: jam A untuk carousel Senin dan Kamis
Minggu 3-4: jam B untuk carousel Senin dan Kamis (topik setara)
Bandingkan median jangkauan dan simpan; ubah hanya jam.
```

## Rekomendasi yang baik
- Satu kalimat temuan + angka + n + tingkat keyakinan.
- Satu tindakan yang bisa dilakukan minggu depan.
- Cara memeriksa apakah berhasil.

## Templat ringkasan balasan
```
Ringkasan: (satu kalimat)
Yang cukup jelas: ...
Yang belum bisa disimpulkan: ...
3 perubahan: 1) ... (alasan, n, keyakinan, cara uji)
Data yang perlu dicatat berikutnya: ...
```

## Mengambil data
Ambil angka dari Insights bawaan tiap aplikasi atau alat penjadwalan yang dipakai. Nama menu dan kolom ekspor berbeda dan bisa berubah; jika ekspor tidak tersedia, salin angka per posting secara manual ke templat CSV. Data pesan masuk biasanya perlu dicatat sendiri.
